# Patricia Lisbona · Diseño web

Web estática en español, sin instalación ni compilación. HTML, CSS y JavaScript editables. Incluye imágenes y tipografía locales, navegación móvil, preguntas desplegables, WhatsApp y correo. No necesita React, npm ni una base de datos.

## Abrir y subir

1. Descomprime el ZIP y abre `index.html` en tu navegador.
2. Para Hostinger, conserva antes una copia de la web actual. Sube el contenido de esta carpeta (index.html, styles.css, script.js, robots.txt, sitemap.xml y assets/) al directorio público del dominio, normalmente `public_html`. No subas la carpeta contenedora como un nivel adicional.
3. Conserva configuraciones del alojamiento y archivos de otros servicios. No es necesario subir LEEME.md ni FUENTES.md.
4. Para GitHub Pages, estos mismos archivos pueden ir en la raíz publicada, conservando el archivo CNAME del dominio existente.
5. Los metadatos y el sitemap usan https://www.patricialisbona.es/. Si publicas en otro dominio, actualízalos.

## Editar

- Textos, enlaces y preguntas: `index.html`.
- Colores, tamaños y distribución: `styles.css`.
- Menú móvil y año del pie: `script.js`.
- Fotografía: `assets/patricia.jpg`. Mantén el nombre o actualiza index.html y la imagen social.
- Contactos conservados: WhatsApp +34 654 687 464; correo patricia.lisbona.ci@gmail.com.
